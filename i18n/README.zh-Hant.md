《*How You Got Rich*》坦率追問：人們如何創造、守住並運用財富，又如何讓
財富成為自由，而不是一場沒有終點的地位競賽。School of Hard Knocks 的
訪談構成全書的人物與證據主線。書中的成功故事會同時面對失敗、運氣、起點、
誘因、生存者偏差，以及由他人承擔的代價。

## 更完整的財富定義

| 富足 · Abundance | 滿足 · Fulfillment | 知足 · Contentment |
| --- | --- | --- |
| 擁有足夠的資源、能力、關係、時間、韌性與選擇，不再長期受困於匱乏。 | 把工作與生活用於值得付出心力的目標。 | 在積累反過來支配人生之前，仍有辨認「已經足夠」的自由。 |

財務自由的意義，在於它能為三者騰出空間；它卻不能替我們決定該如何使用
這些空間。

## 全書論證

| 部 | 核心問題 |
| --- | --- |
| I. 錢是為了什麼 | 財富應當支撐怎樣的人生？ |
| II. 創造有價值的事物 | 人們會選擇、信任並為什麼付費？ |
| III. 擁有那台機器 | 如何把努力變成能比創作者存續更久的資產？ |
| IV. 資本、風險與時間 | 如何讓金錢複利成長，同時不毀掉它的主人？ |
| V. 自由與足夠 | 當生存不再是唯一問題，財富究竟為了什麼？ |

## 建置與驗證

請安裝包含 `pdflatex` 的 TeX Live，以及 `python3`、`rsync`、Poppler 和
`qpdf`。

```bash
make full
make pocket
make verify
make verify-site
make serve
```

網站原始碼位於 [`docs/`](../docs/)，可編輯書稿位於
[`source/`](../source/)。

## 來源與致謝

本書是獨立整理與寫作，主要根據由 **James Dumoulin** 主持的 **School of
Hard Knocks** 訪談，以及每位受訪者分享的經歷。收錄他們的故事，並不表示
他們審閱或認可本書。[`sources/interviews.csv`](../sources/interviews.csv)
記錄了 135 項來源，但不會重新散布訪談轉錄。
